# Kids Colour Game 🎨

A fun, interactive, and simple web-based color game designed to help kids learn colors, alphabets, and numbers while unleashing their creativity!

## ✨ Features
- **100k+ Unique Patterns:** An endless variety of coloring pages to keep kids entertained.
- **Magical Fill Tool:** Tap to fill areas with vibrant colors instantly—perfect for little hands!
- **Educational Content:** Includes alphabets and numbers so children can learn while they play.
- **Save & Download:** Easily save and download your child's colorful masterpieces to your device.
- **Kid-Friendly UI:** A bright, intuitive, and distraction-free interface designed specifically for young users.

## 📁 Repository Contents
- `colour_game.html`: The main file containing the HTML, CSS, and JavaScript for the game.

## 🚀 How to Play
Since this is a standard web file, no installation or complex setup is required!
1. Clone or download this repository to your local machine.
2. Locate the `colour_game.html` file.
3. Double-click the file to open it in any modern web browser (like Chrome, Firefox, Safari, or Edge).
4. Start playing and learning!
